# 角色卡与玩家卡写法：人设、提醒、开场白、初始状态

## 人设格式（角色卡与玩家卡通用）

`system_prompt` 按以下格式整理，每一项简洁清晰地定义。不要过拟合，不要写得过度具体，不要举例子。要有个性、有特点，不要塑造脸谱化、大众化的角色。

```
### 角色名

基本信息：姓名，性别，年龄，身高，体重
核心标签：最能反映角色的一个标签
外貌特征：最容易被记住的身体、五官、服饰或异常特征，不必逐项描写所有部位。
性器官：尺寸、形状、颜色、气味、特征的具体描写，用词直白、露骨、低俗
气质表现：写声音、表情、动作、气味、姿态或装饰中最能体现角色辨识度的部分。
过去经历：最关键的出身、经历、创伤、缺失或秘密。
外在性格：角色在他人面前长期表现出的态度、脾气、处事风格或社交面具。
内在性格：角色真实的欲望、恐惧、执念、软肋、矛盾或自我认知。
性格优点：性格能给角色带来的潜在收益，以及在某方面能够通过性格获得成功
性格缺陷：性格能给角色带来的潜在风险，以及在某方面能够通过性格获得失败
世界观：角色视角认为人总体上【人性判断】，社会主要由【核心动力】推动，【规则/权力如何运作】，人与人的关系本质上【关系判断】，而个人在环境与命运面前【能动性判断】
价值观：TA最看重【核心价值】，其次是【次要价值】；在冲突中通常愿意牺牲【可牺牲项】来保护【优先保护项】，但无论代价如何都不会放弃【底线价值】。（生命、自由、尊严、道义、情感、忠诚、归属、声誉、利益、成就、地位、权力）
方法论：面对问题时，角色通常会先【判断什么】，再通过【主要手段】争取【目标】，在必要时愿意【可接受的妥协/代价】，但不会【不可接受的做法】。
对性的态度：开放程度，性在价值观中的位置等
性行为生理反应：淫荡还是性冷淡，积极还是被动等
特殊能力：能力机制清晰具体定义，包括能做到什么，不能做到什么，边界是什么，触发条件是什么，限制是什么，强度如何等。
```

- 没有特殊能力的角色不写「特殊能力」这一项。
- 未成年角色不写「性器官」「对性的态度」「性行为生理反应」三项。

## 角色卡（{{char}}）

- `description`：一句话简介，展示用，不写设定书。
- `system_prompt`：按上面的人设格式写。
- `post_prompt`：每轮输出前的提醒，只放格式与语气约束（如"用第一人称、每次回复不超过三段"）。
- `first_message`：像角色第一次登场的场景，有具体情境和动作，给 {{user}} 留出回应的空间；不要空泛地打招呼。
- 篇幅大的往事、技能细则、只在特定话题出现的记忆 → 写成世界条目，不塞进人设。

## 玩家卡（{{user}}）

- 玩家卡是用户在这个世界里扮演的具体人物：有名字、经历、当下处境，而不是模板。
- `system_prompt` 按上面的人设格式写；没有开场白和每轮提醒。
- 一个世界可以有多张玩家卡，新建的会成为当前激活的那张。

## 初始状态

- 数值、列表等会变化的信息用 set_state 填，不写进人设（不要在人设里写"好感度=62"）。
- 默认字段的类型：年龄是数字；性格、外貌、穿着、身份是列表，写成数组，如 `["冷静", "克制"]`。
- 需要的字段不存在时，先在世界上建字段，再填值。

## 示例

```
create("character", {
  "name": "沈渡",
  "description": "被教会医院除名的行医人，独自游走于瘟疫边境",
  "system_prompt": "### 沈渡\n\n基本信息：……\n核心标签：……\n外貌特征：……",
  "first_message": "雨夜，破庙里只剩一盏油灯。沈渡抬头看了眼门口浑身湿透的 {{user}}：“伤在哪？”",
  "state": { "性格": ["冷静", "嘴硬心软"], "年龄": 27 }
})
```
