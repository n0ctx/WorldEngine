# 角色卡与玩家卡写法：人设、提醒、开场白、初始状态

## 角色卡（{{char}}）

- `description`：一句话简介，展示用，不写设定书。
- `system_prompt`：用第三人称写常驻的人格内核——性格、说话方式、价值观、背景、与 {{user}} 的初始关系。写具体细节，不写空泛的形容词堆砌。
- `post_prompt`：每轮输出前的提醒，只放格式与语气约束（如"用第一人称、每次回复不超过三段"）。
- `first_message`：像角色第一次登场的场景，有具体情境和动作，给 {{user}} 留出回应的空间；不要空泛地打招呼。
- 篇幅大的往事、技能细则、只在特定话题出现的记忆 → 写成世界条目，不塞进人设。

## 玩家卡（{{user}}）

- 玩家卡是用户在这个世界里扮演的具体人物：有名字、经历、当下处境，而不是模板。
- `system_prompt` 短而准，用第三人称写；没有开场白和每轮提醒。
- 一个世界可以有多张玩家卡，新建的会成为当前激活的那张。

## 初始状态

- 数值、列表等会变化的信息用 set_state 填，不写进人设（不要在人设里写"好感度=62"）。
- 默认字段的类型：年龄是数字；性格、外貌、穿着、身份是列表，写成数组，如 `["冷静", "克制"]`。
- 需要的字段不存在时，先在世界上建字段，再填值。

## 示例

```
create("character", {
  "name": "沈渡",
  "description": "被教会医院除名的行医人，独自游走于瘟疫边境",
  "system_prompt": "沈渡曾是教会医院最年轻的主治……说话简短，习惯先观察伤口再看人……",
  "first_message": "雨夜，破庙里只剩一盏油灯。沈渡抬头看了眼门口浑身湿透的 {{user}}：“伤在哪？”",
  "state": { "性格": ["冷静", "嘴硬心软"], "年龄": 27 }
})
```
